## Осталось: пишущая половина — только с человеком

Агентом это не проверяется по построению: код плана должен произнести человек, иначе
проверяется передача строки между двумя вызовами (см. LIVE-RUN.md, «Чем это не является»).

Прогон в Cursor или в свежей сессии Claude Code, **перезапустив сервер** (`dist` пересобран):

```
1. сделай шапку на листе Проекты жирной
2. пиши <код, который назвало превью>
3. замени в колонке Статус «На приёмке» на «Запущено»
4. пиши <новый код>
5. откати последнюю запись
6. откати последнюю запись
```

| # | Ждём | Дефект |
|---|---|---|
| 1 | превью: ячейки шапки, «было → станет» ПО ВИДУ, код плана; агент просит код у человека | план по значениям; агент подставил код сам |
| 2 | `status: ok`, в журнале строка `formatCells` с `planId` и снимком вида «до» | запись без строки журнала |
| 3 | превью списком затронутых ячеек | «заменено N» вместо списка |
| 4 | `status: ok`, в журнале строка `findReplace` | — |
| 5 | замена откачена, значения вернулись | откатилось не то |
| 6 | вид шапки вернулся | вид не вернулся |

Дополнительно, если не жалко минуты: на шаге 2 назвать **чужой** код (например `ffffff`) —
ждём `plan_mismatch`, отсутствие записи и НОВЫЙ план с новым кодом в том же ответе.

## Непокрытое, названное вслух

- **`format` тела колонки** живьём не подтверждён: на таблице владельца ни одна колонка
  тела не оформлена явно. Нужна колонка с оформленным телом — или это остаётся дырой.
- **`policy://rules` отдаёт только прозу** `rules.md`; машинные правила через ресурс не
  видны, и `write.replace-preview-lists-cells` в тексте не назван по id (T25).
- **Конкурентная правка между превью и записью** (`stale_value` на живой таблице) требует
  второго человека, правящего лист в те же секунды. Проверено тестом, не продом.
