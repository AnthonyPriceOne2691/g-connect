   отдельный тест на «та же ссылка без реестра — read».

3. **Дата приходила в ядро серийным числом.** Sheets API отдаёт у даты сразу два вида —
   `effectiveValue.numberValue` = 46266 и `formattedValue` = «2026-09-01». Адаптер брал
   первое, то есть в карту попадало 46266, тип колонки становился «число», формат даты
   терялся, а запись даты пошла бы числом. **Живое чтение это пропустило** — в той таблице
   нет колонки с датами; поймал тест шва с ответом, собранным по документации. Исправлено
   через `effectiveFormat.numberFormat.type` ∈ {DATE, DATE_TIME, TIME}.
4. **Пример A4 в спеке был несогласован с дизайном:** «Затрачено» → «Часы» это ступень 3
   (подтверждённый алиас), а не ступень 4 (близость) — у слов нет общих букв. Поправлена
   спека, а не порог резолвера: подгонка означала бы, что «Бюджет» тоже «похож» на «Часы».
