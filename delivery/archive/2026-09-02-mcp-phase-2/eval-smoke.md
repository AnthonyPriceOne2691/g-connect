# Eval smoke — эта поставка (фаза 2)

Выведено из acceptance-примеров `spec.md`. Гоняется `npx vitest run` +
`bash delivery/evals/smoke/run.sh` + живая проба сервера через протокол.

## Примеры спеки как оракулы (на моках)

- [x] B1 — ровно шесть инструментов; у каждого имя `gc_*`, заголовок, описание >60 символов и схема входа
- [x] B2 — `gc_targets`: права по целям, состояние аккаунтов; ни токенов, ни путей к профилю
- [x] B3 — `gc_read mode=map`: `headerRow: 2`, колонки с типами и enum, предупреждения; `mode=values` помечает усечение
- [x] B4 — `gc_apply` без `dryRun`: `status: preview`, ноль записей, ноль строк журнала
- [x] B5 — `values: {Бюджет: 100}`: `needs_clarification`, `available` со всеми колонками, подсказка «не угадывай»
- [x] B6 — мусор в операции отклонён до Google (протокольной ошибкой SDK, см. verify-report)
- [x] B6b — цель вне реестра при `dryRun: false`: `policy_denied` / `write.allowlist`, клиент Google не вызывался ни разу
- [x] B7 — правило названо в `cause` и в `detail`
- [x] B8 — `instructions` содержат политику, ссылку на `policy://rules` и число машинных правил
- [x] B9 — запись → `gc_undo`: значения вернулись, в журнале две записи, вторая со ссылкой `undoOf`
- [x] B10 — ревизия сдвинулась: `revision_conflict`, ни одной записи; с `force` откат идёт
- [x] B11 — строка журнала: время, профиль именем, цель, лист, ячейки, ревизии до/после; права 600
- [x] B12 — HTML-превью: «было → станет», вопросы блоком, самодостаточный, экранирует содержимое ячеек
- [x] B13 — одна формулировка из Cursor и Claude Code → один результат. Прогон 2026-09-02:
      первый заход дал шесть дефектов (все починены с оракулами), повторный после правок
      прошёл целиком — запись, откат, `no_change` и `all_undone` сверены с журналом и
      таблицей, а не с пересказом агента
- [x] нулевое изменение не выглядит записью: `no_change`, без журнала и без обращения к Google
- [x] `nothing_to_undo` называет причину из трёх (`journal_empty` / `all_undone` / `id_not_found`)
- [x] лист и шапка из реестра применяются; аргумент вызова старше реестра
- [x] `gc_read values` не отдаёт строк за границей данных, `truncated` считается от данных

  он его не читает; прогон за человеком.

- Docs-примитивы, текстовые селекторы, паритет горячих клавиш — фаза 2.5.
- Реальный сетевой обмен кода на токен — существующий токен покрывает scopes MVP.
