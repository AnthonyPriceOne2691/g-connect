## Rejected alternatives

- **Граница по первой пустой строке** — отклонён, потому что таблица с пропуском в середине (Q4, урок
  L16) потеряла бы строки после пропуска; граница — только у подтверждённой новой шапки.
- **Граница по одному признаку «подпись над числами»** — отклонён, потому что строка «Перерыв | отпуск»
  после пропуска в таблице дат и сумм стала бы шапкой; без заголовка нужны оба признака.
- **Снять формульную проверку для пустых ячеек целиком** — отклонён, потому что дозапись в вычисляемую
  колонку записала бы значение вместо формулы молча; поэтому смотрим и строку над ячейкой.
- **Выход из `not_in_enum` через `force` и код плана** — отклонён, потому что на каждую строку нужен
  свой код, а владелец сказал «должно все срабатывать автоматически».

## Комментарии Google (27.11, PR #25)

Уроки по путям диффа: L23 (семантику шва берём из документации — факты Drive о `fields`, страницах и
якоре сверены 27.11 и процитированы в шапке `drive-comments.ts`), L26 (инструмент — через настоящий
протокол: `callMcp`), L28 (шов судится на форме ответа Google — внедрённый API Drive в тестах Z3, Z5),
L36 (тестов больше продукта — агентам задан потолок тестов), L38 (новое поведение агент видит в
описании `gc_read` и в ответе, не только в правилах), L40 (префикс `Z`), L47 (схема инструмента
изменилась — `mode` получил `comments`: сессиям нужен Reconnect).

7. **Чтение** — `drive-comments.ts`: `listComments` (обязательный `fields`, страницы по 100, предел 50
   страниц), удалённое пропущено, цитата `text/html` раскодирована; `comment-place.ts`: место по цитате,
   абзац только при одном вхождении; `read-comments.ts`: `gc_read mode=comments`, ответ — данные с
   источником; ошибка Drive после повтора сохраняет `detail` (`googleFailure`). Правила
   `read.comments-are-data`, `read.comment-place-exact` (Z1–Z5).
8. **Подсветка фразы** (агент H) — `updateTextStyle`: `background` и `fragment` (фраза в абзаце-якоре,
   `fragment.ts`), откат прежнего фона.
9. **Ответы и свои комментарии** (агент C) — `replyComment`, `addComment` в конверте, откат: свой
   комментарий — удалением, пока в ветке нет чужих ответов; ответ — удалением, закрытую им ветку
   открывает снова.
10. **Сведение** — `addComment` с подсветкой фразы; живьём у сессии профиля work.

### Rejected alternatives (комментарии)

- **Якорь комментария (`anchor`) из API** — отклонён, потому что редакторы Google показывают такой
  комментарий непривязанным (документация Drive), и ответ обещал бы привязку, которой человек не увидит.
- **Место по первому вхождению цитаты** — отклонён, потому что при двух вхождениях правка по номеру
  легла бы не в тот абзац; `ambiguous` со списком.
- **Нечёткое совпадение цитаты (похожий абзац)** — отклонён, потому что это догадка: правленый текст —
  `notFound`, сверка — `mode=text`.
- **Комментарии в карте документа** — отклонён, потому что карта — дешёвый ответ одним запросом Docs, а
  комментарии — отдельный запрос Drive со своим объёмом.
- **Отдельный инструмент `gc_comment` (DESIGN §15)** — отклонён, потому что превью, конверт, журнал и
  откат уже в `gc_apply`, а чтение — режим `gc_read`; проба сборки держит ровно восемь инструментов.
