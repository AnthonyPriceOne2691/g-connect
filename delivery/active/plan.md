# Plan: лист из нескольких таблиц (хотфикс 2026-11-16)

Уроки архива по затронутым путям: L16 (граница дозаписи — по последней строке), L22 (проба судит
обещание правила, а не число), L26 (инструменты — через настоящий протокол), L40 (уникальный
префикс примеров — `Y`), L45 (обратный прогон на базе).

1. **Формулы у ячеек записи** — `guardColumn` получает строки записи: формула в ячейке или строкой
   выше — отказ, иначе заметка; поиск по условию (`findRows`) проверку не проходит; `appendRow`
   судит строку над новой.
2. **Выведенный список — подсказка** — `normalizeValue`: вне выведенного списка — значение по типу
   колонки и заметка; вне списка из проверки данных — `not_in_enum`, как раньше.
3. **`force` под конвертом — только код плана** — `finishWrite` снимает авторизацию конверта, если
   план задевает формулу или защищённый диапазон.
4. **Правила и пробы** — `write.formula-column`, `values.enum-ask`, `write.force-needs-plan`; проба
   `write.force-needs-plan` — и под конвертом; `rules.md` — раздел о листе из нескольких таблиц.

## Rejected alternatives

- **Граница блока в карте** (данные шапки — до пустой строки и следующей шапки) — отклонён, потому что
  меняет данные шапки для дозаписи, поиска и карты (путь урока L16), а хотфикс — сегодня; в «Out of
  scope» спеки.
- **Снять формульную проверку для пустых ячеек целиком** — отклонён, потому что дозапись в вычисляемую
  колонку записала бы значение вместо формулы молча; поэтому смотрим и строку над ячейкой.
- **Выход из `not_in_enum` через `force` и код плана** — отклонён, потому что на каждую строку нужен
  свой код, а владелец сказал «должно все срабатывать автоматически».
