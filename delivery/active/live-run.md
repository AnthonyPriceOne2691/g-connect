## Порядок — несущий

Подключение `--profiles=default,work` ставит сервер на стабильную сборку — поэтому сначала
стабильная из ветки (иначе `g-connect-work` встанет на сборку без профилей и назовёт себя
личным), затем подключение, затем сессии.
