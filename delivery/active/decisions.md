# Decisions

- 2026-11-16 · **Формулы — по ячейке записи и строке над ней** (ведущий) вместо границы блока в карте —
  потому что граница блока меняет данные шапки для дозаписи, поиска и карты (`map.ts`, путь урока
  L16), а хотфикс — сегодня. Цена: строку «Итого» под ячейками ввода не смотрим, и ячейка с пустой
  формулой-пропуском посреди вычисляемой колонки под строкой без формулы пройдёт без отказа.
- 2026-11-16 · **Выведенный список — заметка, а не вопрос** (ведущий) вместо вопроса с выходом через
  `force` — потому что слово владельца «должно все срабатывать автоматически», а правило D-26 и так
  называло список подсказкой. Цена: опечатка варианта выведенного списка («гтово») запишется как
  прислано — превью назовёт список, и агент обязан сказать человеку.
- 2026-11-16 · **Граница блока — консервативная** (ведущий) вместо «до первой пустой строки» — потому
  что ложная граница прячет строки таблицы с пропуском (Q4: дозапись после пропуска, урок L16), а
  пропущенная оставляет прежнее поведение, которое после хотфикса Y1–Y2 уже пишет в ячейки блока. Цена:
  блок «Итоги» без своей шапки и таблица без заголовка с одним признаком границы не получают —
  названо в спеке; `appendRow` при одной пустой строке — отказ с подсказкой, а не вставка сама.
- 2026-11-16 · **`force` под конвертом — только код плана** (ведущий) вместо прежнего «конверт решает
  по операции и числу ячеек» — потому что `write.force-needs-plan` обещал это, а тест листа из нескольких таблиц показал
  запись в E7 поверх формулы с первой фразы. Цена: формулу затирают теперь только кодом плана и под
  разрешением проекта (`riskNeedsCode` в `commit.ts`).
- 2026-11-27 · **Место комментария — по цитате, абзац только при одном вхождении** (ведущий) вместо якоря
  Drive — потому что якорь комментария к документу — внутренние данные редактора, которые Drive называет
  непрозрачными. Цена: правленый после комментария текст — `notFound`, частая короткая цитата —
  `ambiguous`; агент сверяет с `mode=text` или спрашивает человека.
- 2026-11-27 · **Комментарии — режим `gc_read`, запись — операции `gc_apply`** (ведущий) вместо нового
  инструмента `gc_comment` из DESIGN §15 — потому что превью, конверт, журнал и откат уже живут в
  `gc_apply`. Цена: схема `gc_read` изменилась — сессиям нужен Reconnect (L47).
- 2026-11-27 · **Комментарии таблицы — без места** (ведущий) вместо отказа — потому что тот же запрос Drive
  отдаёт их бесплатно, а ячейку из якоря таблиц не достать. Цена: агент видит цитату-значение без ячейки;
  предупреждение это называет.
