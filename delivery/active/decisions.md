# Decisions — G connect из любого проекта (разрешение касанием)

Формат: выбрал X **вместо** Y — потому что Z, цена числом или ссылкой в код.

## Решения владельца (2026-10-17, вопросы с вариантами — ответы его)

- **Касание открывает «всё своё на срок»** вместо «только созданное под разрешением» и вместо
  реестра на проект — потому что его способ работы — таблицы и документы из любого проекта
  (слово 2026-10-13): читать всё, создавать в «Моём диске», писать в любые свои таблицы и
  документы через превью, журнал и откат; разрушающее — по-прежнему его фразой с кодом плана.
  Цена: ошибка агента внутри срока достаёт до любого своего файла — её держат превью, журнал
  с откатом и фраза на разрушающем.
- **Срок — до конца дня (23:59 местного)** вместо часа и вместо «до отзыва» — потому что
  рабочий день — естественная граница сессий. Цена: разрешение переживает конец задачи;
  отзыв раньше срока — `gc grant --revoke`.
- **Механизм — Secretive и Touch ID** вместо фразы в чате — потому что ключ Secure Enclave
  уже стоит на машине, а палец агент не подделает (предложение владельца). Цена — в решении
  агента ниже: окно Touch ID говорит словами Secretive.
- **Клиент — только Claude Code** вместо Claude Code + Cursor + Codex — потому что владелец
  работает в Claude Code. Цена: в Cursor и Codex G connect не появляется; проектная запись
  `.cursor/mcp.json` в репозитории остаётся как есть.

## Решения агента

- 2026-10-17 **Разрешение — подпись ключом Secure Enclave через агента Secretive**
  (`ssh-keygen -Y sign -n g-connect-grant`) вместо фразы в чате и вместо своего помощника на
  Swift с LocalAuthentication — потому что подпись проверяет любой процесс, а фразу — только
  сессия, где она сказана; помощник без entitlements не держит ключ в Secure Enclave
  постоянно, а «Touch ID прошёл» без криптографии подделывается записью файла. Цена: в окне
  Touch ID текст Secretive, а не наш; без запущенного агента Secretive разрешения нет —
  только чтение.
- 2026-10-17 **Ключ проверки берётся у агента Secretive по имени** (`ssh-add -L`) вместо
  файла `~/.gconnect/grant-signer.pub` — потому что файл агент с доступом к диску подменил бы
  своим программным ключом и подписывал бы без пальца. Цена: каждый запуск сервера
  спрашивает агента Secretive; агент не отвечает — разрешение не принимается.
- 2026-10-17 **Проект вызова — `CLAUDE_PROJECT_DIR`** вместо каталога процесса сервера —
  потому что сервер уровня пользователя запускается клиентом, и только переменная клиента
  называет проект сессии. Цена: без переменной проекта нет — только чтение (T5).
