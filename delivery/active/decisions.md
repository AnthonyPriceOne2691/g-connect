# Decisions

Одна строка на выбор. Три части обязательны: **что выбрано**, **вместо чего**,
**потому что**. Строка без альтернативы — не решение, а отчёт о сделанном, и
`delivery_check` её отклонит.

На handoff перечитай: то, что оказалось уроком **о системе** (а не о твоём
выборе), перенеси строкой в `archive/INDEX.md` (§2.2a). Решение умирает с
поставкой, урок — нет.

- 2026-09-01 · выбрал инжектировать Google-клиент интерфейсом `SheetsClient` вместо класса-обёртки над `googleapis` — потому что обёртка тянет типы библиотеки в тесты и фейк пришлось бы строить под форму `googleapis`, а не под нужды ядра; с интерфейсом 11 примеров из 12 закрываются без сети
- 2026-09-01 · выбрал копировать креды в `~/.gconnect/default/` вместо переноса — потому что перенос сломал бы работающий `Gdocs-tabs editor` в трёх папках раньше, чем новое ядро подтверждено на живой таблице
- 2026-09-01 · выбрал начать со Sheets вместо Docs — потому что Docs-примитивы требуют пересчёта `startIndex/endIndex` между операциями, а первым сценариям владельца это не нужно (D-3)
- 2026-09-01 · выбрал поправить пример A4 в спеке вместо подгонки резолвера под него — потому что «Затрачено» и «Часы» не имеют ни одной общей буквы: строковая близость такое не находит и не должна, это ступень 3 (подтверждённый алиас из реестра), а не ступень 4. Подгонка означала бы фаззи-порог, при котором «Бюджет» тоже «похож» на «Часы», то есть тихую запись не в ту колонку
- 2026-09-01 · выбрал отложить zod-схему операций в фазу 2 вместо фазы 1 — потому что в фазе 1 ядро вызывается только из тестов, где типы TS строже схемы; валидировать надо внешнюю границу, а она появляется вместе с MCP (3 инструмента на входе), иначе схема дублирует типы и расходится с ними
- 2026-09-01 · выбрал разделить `SheetMap` (для агента) и `SheetData` (для операций) вместо одного типа — потому что операциям нужны все строки, а в ответ агенту 5000 строк класть нельзя (§7); один тип означал бы либо выжигание контекста, либо второй проход по API за данными
