## Slice 1 — шов `age`

- [x] T1: `src/core/token/age.ts` — зашифровать (stdin → armored stdout, без касания) и
      расшифровать (stdin → stdout, окно плагина); абсолютные пути программ, фиксированный
      `PATH`, ожидание 60 с с убийством процесса; исходы `seal_tool_missing` /
      `unlock_declined` / `internal`. Оракулы на настоящем `age` с ключом X25519: круг

      `seal_tool_missing`; медленная программа → `unlock_declined` за отведённое время.
      Обратные прогоны: подмена `PATH` сессии не влияет; без убийства по таймеру тест висит
- [x] T2: ключ анклава — `age-plugin-se keygen --access-control=any-biometry-or-passcode`;
      получатель — из строки `# public key` файла ключа (без вызова плагина); keygen — на
      заглушке, настоящий — в живом `gc seal`
